# KRA 공공데이터 실호출 검증 — 학습 활용 가능 데이터 인벤토리

**검증 방법:** 발급받은 개발계정 인증키로 승인된 7종 전부 실호출. 응답 본문·필드·결측률·과거 커버리지를 직접 측정. 명세는 data.go.kr 페이지에 인라인된 Swagger JSON + 참고문서 docx에서 추출 후 실호출로 교차 확인.

## 0. 한 문단 요약

**승인된 7종 전부 정상 동작한다(7/7, `resultCode=00`).** 그리고 **학습 원장은 사실상 하나면 된다 — `경주기록 정보`(API4_3/raceResult_3), 필드 93개, 2000년~현재 697,876행.** 여기에 날씨·주로상태·마체중·부담중량·확정배당률·구간기록·상금·휴양일수가 전부 들어 있다. 나머지 6종은 보조이거나 **쓰면 안 되는 것(누수)**이다. 이름이 `AI학습용`인 데이터셋은 오히려 필드가 27개로 빈약하다.

### ⚠ 함정 1 — 참고문서(docx)의 엔드포인트가 폐기된 것이 있다

data.go.kr 참고문서에 적힌 주소를 그대로 쓰면 **`NO_OPENAPI_SERVICE_ERROR`(해당 오픈API 서비스가 없거나 폐기됨)**가 난다. 실제 경로는 버전 접미사가 붙은 형태다.

| 데이터셋 | docx가 말한 주소 (죽음) | **실제 동작 주소** |
|---|---|---|
| 마필 구간별 | `API37/sectionRecord` | `API37_1/sectionRecord_1` |
| 확정배당율 통합 | `API160/integratedInfo` | `API160_1/integratedInfo_1` |

패턴은 `API{n}_{v}/{op}_{v}`. **엔드포인트는 페이지에 인라인된 Swagger JSON이 정답**이다(docx보다 최신).

### ⚠ 함정 2 — 에러코드로 원인을 구분할 수 있다

| 에러 | 뜻 | 대응 |
|---|---|---|
| `NO_OPENAPI_SERVICE_ERROR` | 경로가 틀렸거나 폐기됨 | 버전 접미사 확인 |
| `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 경로는 맞으나 **그 API를 신청 안 함** | data.go.kr에서 추가 신청 |
| `SERVICE_ACCESS_DENIED` | 승인 대기/거부 | 승인 상태 확인 |

경로 탐색 시 이 둘을 구분하면 "주소가 틀린 건지, 신청을 안 한 건지"가 바로 나온다.

## 2. 학습 원장 — `API4_3/raceResult_3` 93필드

요청 파라미터: `meet`(1서울/2제주/3부산경남), `rc_date`, `rc_month`, `rc_no`, `rc_year` — **전부 옵션**. `rc_month` 단위로 긁는 것이 가장 효율적이다.

### 2.1 필드 분류 (ML 관점)

| 그룹 | 필드 | 비고 |
|---|---|---|
| **경주 조건** (발주 전 확정) | `rcDate` `rcDay` `rcNo` `rcDist` `meet` `rcName` `rank`(등급조건) `budam`(부담구분) `prizeCond` `ageCond` `sexCond` `ilsu` | `ilsu`=경주일수(직전 출주로부터 경과일) — **휴양 피처가 파생 없이 바로 있다** |
| **환경** (당일 확정) | **`weather`** `track` | `track`은 `"양호 (7%)"` 형식 → 범주 + 함수율 연속값 동시 추출 |

### 2.2 결측률 실측 (2026-05, 2,580행)

| 필드 | 충전율 | 필드 | 충전율 |
|---|---|---|---|
| `weather` `track` `wgHr` `wgBudam` | **100%** | `ord` `ilsu` `rcDist` `age` `sex` | **100%** |
| `jkName` `trName` `owName` | **100%** | `budam` `rank` `prizeCond` `chaksun1` | **100%** |
| `winOdds` `plcOdds` | 98% | `rcTime` | 98% |
| `diffUnit` | 88% | **`rating`** | **76%** ⚠ |

- **`rating` 76%**가 유일한 실질 결측. 신마·미레이팅 마필로 추정 → 결측 지시자(indicator) + 대체값 전략 필요.
- 구간기록이 전체 기준 28~40%로 보이는 건 **결측이 아니라 경마장별 컬럼 분리** 때문이다. 해당 경마장 행만 보면 **97~99% 충전**:

| 경마장 | 표본 | `seG1f` | `buG1f` | `jeG1f` |
|---|---|---|---|---|
| 서울 | 1,067 | **97%** | 0% | 0% |
| 부산경남 | 769 | 0% | **99%** | 0% |
| 제주 | 744 | 0% | 0% | **99%** |

→ **전처리 1순위: `se*`/`bu*`/`je*`를 공통 `S1F/G3F/G1F/코너` 컬럼으로 통합.** 안 하면 GBM이 결측 70%짜리 컬럼 30개를 보게 된다.

## 5. 보조 API의 쓸모

**`API37_1/sectionRecord_1` (마필 구간별)** — 말 1두의 구간별 **최고/최저/평균** 기록(`FRcTime*`/`SRcTime*`/`ARcTime*`, S1F·1~4C·G3F·G1F). `hr_no`로 조회하면 그 말의 여러 경주가 나온다. 각질(선행/추입) 유형화와 거리 적성 피처에 직결. 단, 집계 시점이 명시되지 않아 **누수 여부를 rcDate로 필터해 확인 후 사용**할 것.

**`API160_1/integratedInfo_1` (확정배당율)** — 경주 1건에 **520행**, 승식 7종: 삼쌍승식 336 · 쌍승식 56 · 삼복승식 56 · 복승식 28 · 복연승식 28 · 단승식 8 · 연승식 8. `API4_3`가 단승·연승만 주므로, **조합식 배당까지 쓰는 베팅 전략·기대값 백테스트를 하려면 이것이 필요**하다.

**`API155/raceResult` (AI학습용)** — 27필드로 `API4_3`의 부분집합. 고유한 것은 **`bthd`(생년월일, `2024-05-23` 형식)** 하나뿐 — `age`(정수 연령)보다 정밀한 일 단위 월령을 만들 수 있다. 2020년까지 과거 조회도 된다. **이름과 달리 학습용으로는 `API4_3`가 우월하다.**

## 6. ★ 정정 — 출마표는 별도 API가 필요 없다

**§6 초판은 "승인 7종이 전부 결과 계열이라 출마표(`API154/racePlan`)가 없으면 경기 전 예측이 불가능하다"고 적었다. 틀렸다.**

`API4_3/raceResult_3`는 이름과 달리 **아직 열리지 않은 경기의 엔트리도 이미 제공**한다. 2026-08-27(목) 시점에 이번 주말(8/28~30) 6개 편성 **514두**가 전부 조회된다 — 결과 필드만 비어 있다.

| | 예정 (8/28~30, 514행) | 완료 (8/23 서울, 100행) |
|---|---|---|
| `hrNo` `hrName` `age` `sex` `name` | **100%** | 100% |
| `rcDist` `rank` `budam` `prizeCond` `ageCond` `sexCond` | **100%** | 100% |
| `chulNo`(게이트) `ilsu`(휴양일수) `wgBudam`(부담중량) | **100%** | 100% |
| **`jkNo` `jkName` `trNo` `trName` `owNo` `owName`** | **100%** | 98~100% |
| `chaksun1~5`(상금) | **100%** | 100% |
| `rating` | 76% | 81% |
| `wgHr`(마체중) `track`(주로) `weather`(날씨) | **0%** | 100% |
| `winOdds` `plcOdds`(배당률) | **0%** | 97% |
| `ord` `rcTime` `diffUnit` 구간기록 | **0%** | 87~100% |

**시사점 3가지**

1. **출마표 전용 API 없이 경기 전 예측 파이프라인이 성립한다.** `API154/racePlan`은 있으면 좋지만 차단 요인이 아니다.
2. **`wgHr`·`track`·`weather`는 당일 확정이다.** 전날 예측 모델은 이 셋을 빼거나 예보/직전값으로 대체해야 한다. 당일 발주 직전 모델이면 쓸 수 있다.
3. **배당률은 발주 전 예측의 입력이 될 수 없다.** API가 주는 것은 확정치라 경주 후에 들어온다. 시장 베이스라인(성능 비교 대조군)으로만 쓴다 — Benter식 2단계 결합을 하려면 실시간 배당이 필요한데 그것은 §마사회법 제48조 3항 1호 문제와 겹친다.

## 6-1. 기수·조교사 정보

**원장에 이미 있다** — `jkNo` `jkName` `jkNameEn` `trNo` `trName` `trNameEn` `owNo` `owName` `owNameEn`, 예정 경기에도 **충전율 100%**.

KRA는 기수 전용 데이터셋도 10종 운영한다(기수 상세정보 15056828 · 기수 성적 15056591 · 기수 일자별 통산전적 15138444 · 기수기간별성적비교 15089669 · 현직/퇴직기수 15086329/15086328 등). **그러나 신청할 필요가 없다** — 그 API들은 §4의 누수 문제를 그대로 갖는 **오늘 기준 스냅샷**이기 때문이다.

**누수 없는 방법: 원장에서 컷오프 기준으로 직접 집계한다.** 2023~2026 96,566행에서 `rcDate < 20260828` 행만으로 이번 주말 출전 기수 70명의 전적을 계산한 결과:

| 기수 | 출주 | 1착 | 승률 | 복승률 | 평균착순 |
|---|---|---|---|---|---|
| 서승운 | 1,514 | 352 | **23.2%** | 39.3% | 5.10 |
| 다실바 | 1,518 | 279 | 18.4% | 32.3% | 5.91 |
| 문현진 | 1,732 | 295 | 17.0% | 29.8% | 6.54 |
| … | | | | | |
| (출주 100회 이상 70명) | | | 중앙값 **8.1%** · 최저 2.2% · 최고 23.2% | | |

**승률이 2.2%~23.2%로 10배 벌어진다 — 기수는 강한 예측 변수다.** 그리고 이 수치는 예측 시점에 실제로 알 수 있었던 정보만으로 만들어졌다. 조교사도 동일 방식(82명).
