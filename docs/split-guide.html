2026-09-01 재학습 기준. valid·test 경계는 매주 월요일 함께 이동합니다 — 평가 구간이 특정 연도에 고정돼 있으면 갈수록 무의미해지기 때문입니다. game 예약분만 고정입니다.

게임 구간을 뒤쪽 시간 블록이 아니라 흩어서 예약한 이유가 있습니다. 주말 실시간 예측을 하려면 2025~2026년 데이터를 학습에 넣어야 하는데, 게임풀이 맨 뒤에 있으면 매주 재학습할 때마다 게임 경주가 학습에 흡수됩니다. 개최일 단위로 흩어 예약하면 재학습을 아무리 돌려도 게임풀은 계속 미학습으로 남습니다.

경주 단위가 아니라 개최일 통째로 뺀 것도 의도입니다. 경주 단위로 흩뿌리면 같은 날 앞뒤 경주가 학습에 남아 애매해집니다.

절대 규칙

1

game 구간은 학습·검증·평가 어디에도 쓰지 않습니다

모델이 그 경주를 본 적 있으면 비정상적으로 잘 맞힙니다. 일반화가 아니라 부분적으로 외운 겁니다. 그러면 "내 모델 vs 기본 모델 vs 시장" 비교가 통째로 무의미해집니다.

2

game_holdout.json은 재생성하지 않습니다

시드 20260901로 뽑은 408개 개최일이 들어 있습니다. 이 파일이 바뀌는 순간 예약이 무의미해집니다. 빌더가 매번 이 파일을 읽어 학습에서 뺍니다.

3

test는 각자 최종 1회만 엽니다

6명이 각자 튜닝하며 test를 반복해 열어보면 그 순간 test가 valid가 됩니다. 튜닝은 valid로, test는 마지막 비교 때 한 번. 802경주에서 top-1 적중률의 표준오차가 1.7%p이니, 그보다 작은 차이는 우열로 읽지 마세요.

4

valid·test는 개발 단계 전용입니다

하이퍼파라미터가 정해지고 6명 비교가 끝나면, 운영 모델은 game을 뺀 전부(train+valid+test)로 매주 재학습합니다. 그래야 주말 실시간 예측에 최신 10개월이 들어갑니다. game만 영구 제외입니다.

여기에 경주 내 정규화 26개가 붙습니다. 주요 연속형 13개에 _z(경주 내 z-score)와 _rk(순위 백분위)를 만들어 뒀습니다. F3_jk_win_rate_365 = 0.15가 좋은 값인지는 같은 경주 다른 기수들이 몇인지에 달렸으니, 그 상대값을 직접 준 겁니다.

두 종류의 태그를 확인하세요

vol — UI 슬라이더 대상 25개

경기마다 바뀌는 피처만 사용자가 조절하게 합니다. 날씨·주로·인기도·기수·게이트·거리가 여기 들어가고, 혈통·성별·산지는 static이라 슬라이더에서 뺍니다.

tier=G — 리플레이 전용 4개

인기도(F6)는 주말 실시간 예측에 쓸 수 없습니다. 과거 경주 리플레이에서는 배당이 확정돼 있어 쓸 수 있지만, 실제 주말 경기는 발주 4분 전에도 배당이 0행입니다(실측). 실시간 모델은 반드시 features(exclude_tier=("G",))로 F6를 빼고 학습·추론해야 합니다.

즉 모델이 두 개 나옵니다 — 게임용(82개)과 주말 실시간용(78개).

시작하기

import pandas as pd
from schema_v2 import features, GROUPS

tr = pd.read_parquet("dataset/v2/model/train.parquet")
va = pd.read_parquet("dataset/v2/model/valid.parquet")

MY = "F3"                              # 자기 담당 그룹
cols = features(groups=["X", MY])      # 공통 + 내 그룹

# 랭킹 학습 — 경주 단위 상대비교가 이 문제의 본질(Bolton & Chapman 1986)
import lightgbm as lgb
g_tr = tr.groupby("race_id", sort=False).size().to_numpy()
model = lgb.LGBMRanker(objective="lambdarank")
model.fit(tr[cols], tr["y_rel"], group=g_tr,
          categorical_feature=[c for c in cols if str(tr[c].dtype) == "category"])
정렬을 건드리지 마세요. parquet은 race_id 기준으로 묶여 있습니다. LightGBM의 group은 "연속된 N행이 한 경주"라고 가정하므로, 셔플하면 에러 없이 조용히 틀린 모델이 나옵니다.

공통 평가 지표

같은 test 셋에서 아래를 전부 보고합니다.

  • Top-1 적중률 — 1위 예측이 실제 1착인 비율
  • Top-3 적중률, NDCG@3
  • vs 시장 베이스라인 — 인기 1위마 단순 베팅 대비

마지막 줄이 핵심입니다. 이 test 셋의 실측 시장 베이스라인은 단승 34.2% · 복승 65.7%입니다. 선행연구에서 신뢰할 수 있는 숫자는 단승 40%대이고, 90%대 정확도는 클래스 불균형 아티팩트이니 그런 숫자가 나오면 버그를 의심하세요.
